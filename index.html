Ce que j'ai construit

● réalisé

Industrialisation DevOps d'un parc IT

Application Flask de gestion de parc informatique (inventaire, tableau de bord, découverte réseau, journal d'audit), utilisée comme support d'une chaîne DevOps complète. Elle est conteneurisée avec Docker, livrée par un pipeline GitHub Actions, décrite en Terraform sur AWS (VPC, sous-réseaux, groupes de sécurité) et supervisée avec Prometheus et Grafana.

Derrière Nginx, Flask et gunicorn s'appuient sur PostgreSQL. Chaque pull request passe par les tests, le scan de sécurité de l'image et la validation Terraform avant la fusion.

● réalisé · projet d'équipe

ChriOnline

Application e-commerce client-serveur en Java (JavaFX 21, MySQL) avec communication TCP et UDP, conçue pour gérer plusieurs clients simultanément. Soutenue en mai 2026.

  • Mon rôle : chiffrement AES-256-GCM
  • Serveur multi-thread : plusieurs clients en parallèle
  • Protection contre les attaques par force brute
  • Flux sécurisés d'entrée et de sortie, démo de chiffrement
  • Débogage de compatibilité JavaFX (migration vers Ikonli)
● réalisé

TempCast : prévision de température

Tableau de bord web (application monopage) pour visualiser, tester et comparer cinq modèles de prédiction de température : trois approches de machine learning (Persistence, régression linéaire, KNN) et deux modèles de deep learning (GRU, LSTM).

  • Trois vues : aperçu, prédiction en temps réel, comparaison des modèles
  • API Flask pour lister les modèles, prédire, tracer et comparer
  • Graphiques prédit contre réel, métriques RMSE, MAE et R²

Garder le parc informatique à jour et les utilisateurs opérationnels

Au sein de l'équipe Support IT, j'ai tenu à jour l'inventaire du parc informatique, suivi le stock de matériel et dépanné les utilisateurs au quotidien.

J'ai aussi documenté les interventions réalisées pour faciliter le dépannage des problèmes récurrents.

Ce que j'ai fait

  • Inventorier les équipements (PC, imprimantes, toners) dans un logiciel de gestion de parc, pour une vue à jour du matériel
  • Suivre le stock (entrées, sorties, disponibilités) pour anticiper les besoins et éviter les ruptures
  • Assurer le support de premier niveau : pannes de poste, imprimante, accès réseau
  • Documenter les interventions et rédiger des fiches de procédures
